# Валютный ETL и Data Quality сервис

Микросервис на FastAPI, который симулирует ETL-процесс: принимает курсы валют из внешних источников, проверяет их на аномалии (Data Quality) и сохраняет в готовую витрину данных.

## Стек

* **Backend:** Python, FastAPI, Pydantic
* **Тесты:** pytest, httpx
* **CI:** GitHub Actions

## Список маршрутов API (EndPoints)

| Тип | Маршрут | Описание | Data Quality Контроль / Валидация |
| :--- | :--- | :--- | :--- |
| **GET** | `/health` | Проверка работоспособности сервиса. | Возвращает `{"status": "OK"}` при исправной работе. |
| **GET** | `/version` | Получение текущей версии приложения. | Показывает версию проекта и тип окружения (`.env`). |
| **POST** | `/etl/load-rate` | Входной эндпоинт для загрузки данных (валюта и курс). | **Критическая проверка:** если курс `rate` $\le$ 0, запрос блокируется с ошибкой `400 Bad Request`. |
| **GET** | `/dwh/rates` | Витрина данных (DWH) для аналитиков и BI-систем. | Отдает список только тех валют, которые успешно прошли проверку. |
| **GET** | `/dwh/rates/{currency_code}` | Получение курса конкретной валюты. | Если валюта отсутствует в базе, возвращает ошибку `404 Not Found`. |
| **DELETE** | `/dwh/rates/{currency_code}` | Удаление валюты из витрины данных. | Если валюта найдена — удаляет её, иначе возвращает ошибку `404 Not Found`. |

### Пример тела запроса для `POST /etl/load-rate`:
```json
{
  "currency": "USD",
  "rate": 95.5
}
```

## Как запустить проект локально

1. Активируйте виртуальное окружение:
   ```bash
   source venv/bin/activate
   ```

2. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```

3. Запустите сервер:
   ```bash
   uvicorn main:app --reload
   ```
   После этого интерактивный интерфейс приложения будет доступен по адресу: http://127.0.0.1:8000/docs

## Проверка приложения и логи

```bash
curl http://127.0.0.1:8000/health # {"status":"ok"}
curl http://127.0.0.1:8000/version # {"version":"1.0.0"}
```
Логи выводятся в терминал, где запущен сервер:

```bash
INFO: Application started: version=1.0.0, data_dir=data
INFO: Link created: id=2, collection_id=2
WARNING: Duplicate link: existing_id=2
```

Для добавления нового курса валюты откройте интерактивную документацию по адресу http://127.0.0.1:8000/docs, заполните название валюты и её текущий курс в эндпоинте POST /etl/load-rate. В ответ придет статус об успешном сохранении в витрину данных.

Название валюты обязательно (например, USD, EUR). Курс валюты должен быть строго больше нуля. Запросы с нулевым или отрицательным курсом автоматически отклоняются системой контроля качества данных (Data Quality).

Запись также можно создать, прочитать или удалить через соответствующие методы по адресу http://127.0.0.1:8000/docs

### Дополнительные способы тестирования

#### Автоматический запуск тестов pytest
Для комплексной проверки всей логики выполните команду в терминале:
```bash
./venv/bin/python3 -m pytest
```

## 🛠 Диагностика и решение проблем

### 1. Ошибка `ModuleNotFoundError: No module named 'fastapi'` при запуске тестов
* **Причина:** На Mac глобальный `pytest` (например, из Anaconda) может перехватывать управление.
* **Решение:** Запускайте тесты строго через Python из вашего виртуального окружения по его прямому адресу:
  ```bash
  ./venv/bin/python3 -m pytest
  ```

### 2. Ошибка `ERROR: [Errno 48] Address already in use` при запуске сервера
* **Причина:** Порт 8000 уже занят другим процессом или запущенной ранее копией приложения.
* **Решение:** Запустите сервис на другом свободном порту, например 8080:
  ```bash
  uvicorn main:app --reload --port 8080
  ```
