# Валютный ETL и Data Quality Сервис

Микросервис на FastAPI, который симулирует ETL-процесс: принимает курсы валют от внешних источников, проверяет их на аномалии (Data Quality) и сохраняет в готовую витрину данных.

## Стек технологий
* Python 3.11+
* FastAPI & Uvicorn
* Pydantic
* Pytest & HTTPX

## Список маршрутов API (EndPoints)

### ⚙️ Технические маршруты
* **`GET /health`** — Проверка работоспособности сервиса. Возвращает `{"status": "OK"}`.
* **`GET /version`** — Получение текущей версии приложения и окружения.

### 🔄 ETL & Data Quality
* **`POST /etl/load-rate`** — Входной эндпоинт для загрузки данных. Принимает JSON с валютой и курсом. 
  * *Data Quality контроль:* Если переданный курс валюты `rate` меньше или равен 0, сервис блокирует запись и возвращает ошибку `400 Bad Request`.
  * *Пример тела запроса:*
    ```json
    {
      "currency": "USD",
      "rate": 95.5
    }
    ```

### 📊 Витрина данных (DWH)
* **`GET /dwh/rates`** — Возвращает весь список успешно сохраненных и очищенных курсов валют для дальнейшего анализа или выгрузки в BI-системы (например, Яндекс DataLens).

## Как запустить проект локально

1. Активируйте виртуальное окружение:
   ```bash
   source venv/bin/activate
   ```

2. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```

3. Запустите сервер:
   ```bash
   uvicorn main:app --reload
   ```
   После этого интерактивный интерфейс приложения будет доступен по адресу: http://127.0.0

## Как запустить автоматические тесты
```bash
python -m pytest
```

## 🛠 Диагностика и решение проблем

### 1. Ошибка `ModuleNotFoundError: No module named 'fastapi'` при запуске тестов
* **Причина:** На Mac глобальный `pytest` (например, из Anaconda) может перехватывать управление.
* **Решение:** Запускайте тесты строго через Python из вашего виртуального окружения:
  ```bash
  python -m pytest
  ```

### 2. Ошибка `ERROR: [Errno 48] Address already in use` при запуске сервера
* **Причина:** Порт 8000 уже занят другим процессом или запущенной ранее копией приложения.
* **Решение:** Запустите сервис на другом свободном порту, например 8080:
  ```bash
  uvicorn main:app --reload --port 8080
  ```

### 3. Изменения в коде не отображаются в браузере
* **Причина:** Сервер запущен без флага автоматической перезагрузки.
* **Решение:** Убедитесь, что вы запускаете проект с флагом `--reload`.
